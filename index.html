Writeups

Full analyses with reproduction steps in the portfolio repo.

01ValidatorRegistry registration ID 0 sentinel collision
registerValidator() assigns IDs via post-increment from an uninitialized counter. The docs say the counter starts at 1 — but no on-chain code enforces it. Miss the genesis storage poke and the first validator gets ID 0, the reserved "not a controller" sentinel: permanently locked at zero voting power, no recovery function. Includes a 4-test Foundry PoC.

02MCP SDK AJV $async validation bypass + client crash
A schema containing $async: true compiles to an async validator returning a Promise — always truthy, so every input passes. Because MCP servers supply the output schema, a malicious server disables the client's only containment check and kills the host via unhandled rejection. Second class measured in the same path: attacker-supplied pattern blocks the event loop for 55 seconds.
TypeScriptAJVCWE-20ReDoS
03Timelock treasury withdrawal does not bind recipient
The timelock announces an amount and recipient at queue time, but executeTreasuryWithdrawal pays whatever recipient is passed at execution time. Verified on local anvil: queueTreasuryWithdrawal(A, 9e15) then executeTreasuryWithdrawal(1, B) paid B, not A — announced recipient received 0, arbitrary sink received the full amount.
SolidityAnvil PoCTimelockFund flow
04remove_controller leaves orphaned minters able to mint
The doc says it "removes its minter" — the code only deletes the controller mapping. Role::Minter and the minter_allowed allowance survive, and mint() checks nothing else. Minter key rotation and decommissioning are both no-ops on the old minter. No recovery exists: RemoveMinter requires the very controller mapping that was just deleted. Found by reading 8 Rust files end to end.
RustNEARCWE-459Access control
05Runtime authorization replay — signed nonce never enforced
executeWithRuntimeValidation accepts an authorization whose nonce is signed by the multisig signers but never stored or validated on-chain. An executed authorization can be resubmitted indefinitely by the bound sender. The userOp path is protected by the EntryPoint nonce; only the native runtime path is affected. Hardhat PoC: 3/3 tests passing.
SolidityERC-4337/6900Hardhat PoCReplay
06DataDome bot protection — automated challenge bypass
DataDome's multi-stage JS challenge (403 → c.js → captcha iframe → interstitial fingerprinting) is solvable by an automated real-browser client: Playwright driving system Edge with two stealth patches clears the full chain in ~5-6 seconds with zero human interaction. Each solved session yields ~90 requests before re-challenge; rotating browser contexts sustains scraping indefinitely. Measured protection profile: ~100 requests per session cookie, ~1,000 requests per IP flag-window, escalating cooldowns on repeat offense (6→15→60+ min), and per-host variance (nginx viable; nodejs/fastly/cloudfront effectively dead). 4,847 requests verified with HTTP 200 + pagehash flags from a single disclosed IP before the run was stopped at 16% of the 30K target — the IP-level volume cap, not the bypass, is the binding constraint. Methodology

How findings get found — and why they hold up in triage.

1

Program selection

Newly launched or low-competition programs where source code is in scope. Web surfaces get 3,000+ reports per quarter; source repos get a handful. Go where the scanners aren't.

2

Source-code-first

Clone the repo, read the core contracts/services end to end before touching any live endpoint. The high-severity tier lives in consensus-critical logic, not missing headers.

3

Sink identification

Map every trust boundary first — who supplies what data to whom — then audit the sinks: signature construction, access-control sentinels, initialization paths, schema validators.

4

PoC before claim

Every finding gets a runnable proof (Foundry test, standalone script) executed locally. If it doesn't run, it doesn't get reported.

5

Honest severity

Check for recovery paths and compensating controls before claiming impact. An accurate Low builds Signal; an inflated Medium burns it.
